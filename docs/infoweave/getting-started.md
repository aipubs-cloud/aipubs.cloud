# Getting Started with InfoWeave

## Overview

InfoWeave provides a structured environment for creating AI workflows with execution controls, governance, and provenance.

## Core Concepts

### Workflows

Composable execution paths that define how AI components interact.

### Policies

Rules and constraints that guide system behavior.

### Provenance

Artifact history and verification mechanisms powered by AIPubs.cloud provenance infrastructure.
